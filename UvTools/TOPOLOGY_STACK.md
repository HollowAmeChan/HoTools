# 拓扑堆叠

UV 编辑器 → 右键 → HoTools → **拓扑堆叠**，或 F3 搜索“拓扑堆叠”。
操作符：`ho.uvtools_topology_stack`。更新插件后需重新加载插件或重启 Blender。

取消堆叠入口在此菜单项正下方，支持横向、纵向排列与烘焙用 +1U 跨象限偏移，
具体用法见 `UV_UNSTACK.md`。

1. 在网格编辑模式选择要堆叠的 UV 岛。支持同物体多个岛和多物体编辑。
2. 希望保留某个岛的位置时，让该岛包含活动网格面，并使其物体成为活动物体。
   没有有效活动面时优先取活动物体的首个所选岛，再按物体名称/面顺序确定主岛。
3. 执行拓扑堆叠。点数、形状与完整面连接关系匹配的岛自动分组，每组保留一个
   主岛，其他岛的所有 UV 顶点（含内部点）直接复制主岛坐标，自动考虑镜像。
4. 匹配不到但形状接近时，用 F9 调整 **形状容差**。默认 5%，表示统一尺寸并
   匹配旋转/镜像后，最大边界点偏差占主岛边界包围盒对角线的比例。容差只影响识别；
   匹配成功后顶点精确重合，不保留偏差。不限制岛的原始位置、旋转或等比尺寸。
   内部点的位置差异不会阻止堆叠，内部点依据面连接关系强制对齐。

选中岛内一部分 UV 即会处理该完整岛。同步关闭时，所属岛的所有面须在 UV 中
可见（在网格中选中）；带隐藏面或未完整显示的岛跳过并报告。缺失 UV 不自动创建。

固定点坐标也一起强制对齐，pin 标记保留；选择、同步开关、缝线、其他 UV 层和
网格几何保持原状态。支持一次撤销；写回失败则恢复原坐标。

共享网格边的镜像岛堆叠后，可按 UV 面朝向重新识别为独立片，因此再次执行
拓扑堆叠或取消堆叠时不会仅因共享边坐标重合而算成一个岛。坐标保持精确重合，
不添加微量偏移；Blender 原生 Ctrl+L 仍可能将这些重叠片一起选中。

完全对称的岛存在多种同样正确的对应，默认选择最小朝向变化并稳定排序。
此版本仅提供同形状同点数的拓扑堆叠；不同面连接关系、非流形 UV 边或超过匹配
工作量限制时不会强行写入。

测试：`tests/test_uv_topology.py` 为纯算法测试；
`tests/test_blender_uv_topology_stack.py` 在真实 4.5 / 5.2 中验证注册与 BMesh 行为。
本机结果：17 项算法测试通过；4.5.8 集成测试 18 项通过、1 项新版精细同步选择
测试跳过；5.2.0 集成测试 19 项通过，包含后台 Undo/Redo 和失败回滚。
