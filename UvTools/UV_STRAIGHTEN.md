# 线展开与直化

更新插件后，在 UV 编辑器右键 → HoTools 使用 **线展开所选 UV 岛** 和
**直化所选 UV 岛**，也可 F3 搜索。两项都支持多物体编辑与 UV 同步开关。

## 线展开

1. 切到边选择模式，在 UV 中选择需要拉直的开链。
2. 执行“线展开所选 UV 岛”。可以选多个岛，也可以选同岛多条不相交的内部线。
3. F9 设置方向：最近 U/V 轴、水平 U、垂直 V、保留线方向；可切换角度展开或
   保形展开。线的 UV 边长比例与总长保留，岛的其余区域使用 Blender 求解器展开。

方向来自原 UV，拉直前先建立 UV 参考框架，不以网格切向决定方向。每条内部线
隔开的区域分别保留方向锚点，避免对称/镜像岛的一侧翻折到另一侧。

闭环不能整体压成一条直线；分叉与相交线会明确提示。请选不相交的开链，或
分别操作。原固定点默认受保护，若与目标直线冲突则跳过；F9 可取消“尊重原固定点”。

## 直化

选中要处理的岛后执行“直化所选 UV 岛”。

默认算法已改为 **四边形优先**。参考本机 ZenUV Quadrify 的“矩形种子面 +
沿四边形传播”思路，使用独立的拓扑行列求解，不依赖 ZenUV 的安装或注册。
旧方法会漏掉超过角度/偏差阈值的弯曲行列；新方法直接按四边形连接关系生成
笔直、平行且正交的行列，随后直接写 UV，不再调用展开器改变四边化结果。

- **四边形优先**（默认）：规则四边形主体和末端三角尖端按拓扑直化。其他三角面、
  混合面或无法建立统一四边形行列的拓扑，使用原阈值直化。
- **拓扑四边化**：接受可铺成矩形行列网的四边形主体，可带末端三角尖端。
  支持单四边形、规则条带、L 形和带孔的网格。极点、未切开的周期闭环等拓扑
  冲突会明确跳过。
- **阈值直化**：使用原来的近直线识别和约束展开，可继续用于非四边形网格。

四边化优先使用活动面作为种子，没有有效活动面时选择靠近岛中心的面。
行列间距采用对应 3D 边的平均长度，计入物体世界变换与非均匀缩放。
原 UV 决定旋转和镜像朝向，不使用网格切向定方向；没有原 pin 约束时保持
岛的 UV 总面积和独立 UV 点的中心。直线方向默认 **最近 U/V 轴**，生成严格
水平/垂直网格；F9 可明确选“保留线方向”保留倾角。新调用不继承旧版本缓存的
KEEP 参数；当前操作想立即摆正，也可直接在 F9 中切换到“最近 U/V 轴”。

原 pin 优先约束整个矩形网格的位置/缩放/方向。单个 pin 保持原坐标；多个
pin 与矩形网格不兼容时跳过该岛，F9 可关闭“尊重原固定点”。不通过弯曲行列
迎合互相冲突的 pin。支持共享网格、多岛与精确堆叠的镜像岛。

### 发丝的三角尖端

支持“四边形条带 + 单个三角形尖端”，以及多列条带末端汇聚到一个尖点的三角扇，
也支持条带两端都有尖点。先摆正四边形主体，再将尖点放到底边两端的中垂线上；
三角扇使用整个底边链的两端，确保尖点位于条带宽度中央。

尖端高度依据真实 3D 三角形对底边的高，三角扇按底边长度加权平均；计入物体
世界变换与非均匀缩放。UV 总面积与朝向检查包含尖端，不改动网格拓扑。
活动面即使是尖端三角形，也会自动寻找四边形主体作为种子。

仅将直接连接到主体直线边界的末端三角面视作尖端。内部三角化、拐角上的三角扇
仍使用混合面/阈值处理；退化的 3D 尖端会保留原 UV。固定尖点可通过移动整个
条带满足居中；若其他 pin 与居中目标冲突，可在 F9 关闭“尊重原固定点”。

以下参数用于 **阈值直化**（四边形优先模式下的其他拓扑也使用它们），
不会限制拓扑四边化：

- **转角阈值**：相邻边允许偏离直线的最大角度，默认 10 度。
- **全链偏差**：最大垂直偏差占整条链长的比例，默认 0.005（0.5%）。它会
  排除细分圆弧，避免仅因每个局部转角小就把圆弧错误拉直。
- **包含内部线**：默认开启；四边形优先模式关闭时改用边界阈值直化。
- **直线方向**：共享交点通过联合拟合处理，支持三角网格的
  行、列、斜线同时直化。默认摆正到最近 U/V 轴；有三角斜线而无法全吸附轴时，
  联合直化后只将主行列方向整体摆正，保留斜线关系。可明确选“保留线方向”。

## 范围与恢复

这两项会展开所属完整 UV 岛。关闭同步时，需在网格中选中该岛的全部面，使岛
完整显示；隐藏或显示不完整的岛跳过。它们与只处理可见区域的“本象限翻转”不同。

选择、同步开关、选择模式、原 pin、seam、其他 UV 层和网格几何恢复原状态。
阈值路径检查直线/固定点残差、UV 有限值及原网格三角形的朝向；四边化检查
行列拓扑相容性、固定点和各 UV 面的朝向。失败岛保留原坐标，通过的岛一起
提交，支持一次撤销/重做。混合求解最终写回失败时恢复所有参与岛。

测试入口：`tests/test_uv_chains.py`（纯算法）、
`tests/test_blender_uv_straighten.py`（真实 Blender 4.5.8 / 5.2.0 原生展开）。
覆盖多内部线、镜像与旋转、三角面/混合面/五边形/带洞岛、阈值、原固定点冲突、
异常回滚、多物体、共享 mesh、其他 UV 层状态与 Undo/Redo。
当前结果：14 项线算法测试通过。
2026-10-19 更新：另有 `tests/test_uv_quad.py` 的 18 项四边化纯算法测试；
原生直化套件已扩展到每版 41 项，全部通过。新增覆盖明显弯曲行列、严格正交、
3D 平均间距与缩放、旋转/镜像、活动种子、L 形/孔洞、单面、原 pin 冲突、
堆叠镜像岛、四边形与三角面同次处理、写回回滚和 Undo/Redo。
默认摆正另覆盖细长且分段不均的倾斜条带，以及旧 KEEP 参数缓存的原生调用。
三角尖端另覆盖单尖、三角扇、双端、镜像/旋转、3D 高度/缩放、活动三角面、
固定点、只选尖端、退化保护、失败回滚与 Undo/Redo。
