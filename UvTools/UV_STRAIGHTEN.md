# 线展开与直化

更新插件后，在 UV 编辑器右键 → HoTools 使用 **线展开所选 UV 岛** 和
**直化所选 UV 岛**，也可 F3 搜索。两项都支持多物体编辑与 UV 同步开关。

## 线展开

1. 切到边选择模式，在 UV 中选择需要拉直的开链。
2. 执行“线展开所选 UV 岛”。可以选多个岛，也可以选同岛多条不相交的内部线。
3. F9 设置方向：最近 U/V 轴、水平 U、垂直 V、保留线方向；可切换角度展开或
   保形展开。线的 UV 边长比例与总长保留，岛的其余区域使用 Blender 求解器展开。

方向来自原 UV，拉直前先建立 UV 参考框架，不以网格切向决定方向。每条内部线
隔开的区域分别保留方向锚点，避免对称/镜像岛的一侧翻折到另一侧。

闭环不能整体压成一条直线；分叉与相交线会明确提示。请选不相交的开链，或
分别操作。原固定点默认受保护，若与目标直线冲突则跳过；F9 可取消“尊重原固定点”。

## 直化

选中要处理的岛后执行“直化所选 UV 岛”。

- **转角阈值**：相邻边允许偏离直线的最大角度，默认 10 度。
- **全链偏差**：最大垂直偏差占整条链长的比例，默认 0.005（0.5%）。它会
  排除细分圆弧，避免仅因每个局部转角小就把圆弧错误拉直。
- **包含内部线**：默认开启，同时识别边界与内部行列；关闭则只识别边界。
- **直线方向**：默认保留原方向。共享交点通过联合拟合处理，支持三角网格的
  行、列、斜线同时直化。可明确选择“最近 U/V 轴”；不相容的轴向线网会提示。

## 范围与恢复

这两项会展开所属完整 UV 岛。关闭同步时，需在网格中选中该岛的全部面，使岛
完整显示；隐藏或显示不完整的岛跳过。它们与只处理可见区域的“本象限翻转”不同。

选择、同步开关、选择模式、原 pin、seam、其他 UV 层和网格几何恢复原状态。
每个结果都会检查直线/固定点残差、UV 有限值及原网格三角形的朝向；失败岛恢复
原坐标，通过的岛一起提交，支持一次撤销/重做。

测试入口：`tests/test_uv_chains.py`（纯算法）、
`tests/test_blender_uv_straighten.py`（真实 Blender 4.5.8 / 5.2.0 原生展开）。
覆盖多内部线、镜像与旋转、三角面/混合面/五边形/带洞岛、阈值、原固定点冲突、
异常回滚、多物体、共享 mesh、其他 UV 层状态与 Undo/Redo。
当前结果：13 项线算法测试通过，两版各 18 项原生集成测试通过。
