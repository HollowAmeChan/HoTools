# UV 镜像、平移与对齐

重新加载 HoTools 后，在 UV 编辑器右键 → HoTools 使用以下入口，也可 F3 搜索。

**常用快捷入口：本象限左右翻转 / 本象限上下翻转。** 将所选 UV 所在的完整岛
沿该岛所在整数 UV 象限的中线翻到另一半。第一象限分别是 `u'=1-u`、`v'=1-v`；
其他 UDIM 和负坐标象限按各自中线处理。该入口使用象限中心，不使用岛自身中心。
按 UV 编辑器当前可见的岛处理；网格只选中部分面也可直接使用，未显示的 UV
保持原位。跨象限的可见岛跳过并提示，其他符合条件的岛仍然执行。

- **镜像所选 UV**：U/X 左右翻转，V/Y 上下翻转。默认以选区包围盒中心镜像；
  F9 可选择每岛分别镜像、UV 光标、原点或指定中心。坐标直接计算，不受编辑器
  当前变换轴心影响，单点或零宽选区也可处理。
- **平移所选 UV**：方向 ±U/±V，距离默认为 1 UV 单位（一格 UDIM）。F9 改距离
  或选择像素单位；像素按当前图像的宽高分别换算，无有效图像时提示并取消。
- **沿轴对齐所选 UV**：固定 U 成为垂直线，固定 V 成为水平线；支持最小值、
  最大值、平均值、归零与 UV 光标，F9 可启用每岛分别对齐。

Alt+A 对齐保留原 `ho.align_uv` 入口，和右键的新入口共用同一实现。修复了
多物体遗漏、5.2 非同步 API 错误、隐藏 UV 被改、精细同步选择被扩大，以及
视图模式水平/垂直光标按钮轴向颠倒。平均值按 UV 拓扑顶点统计，避免面数权重。

普通点变换只写所选可见角点；本象限中线翻转明确扩展到整岛。不会改变选择、pin、seam、其他
UV 层或网格几何。支持两版同步开关、共享网格数据去重与撤销/重做。

测试：11 项纯算法测试；真实 Blender 4.5.8 / 5.2.0 各 20 项集成测试，4.5
跳过 1 项仅新版才有的精细同步选择测试。另运行拓扑堆叠与饼菜单注册回归测试。
