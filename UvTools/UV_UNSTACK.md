# 取消堆叠

UV 编辑器右键 → HoTools → **取消堆叠**，位于“拓扑堆叠”正下方。
也可 F3 搜索“取消堆叠 UV 岛”。执行前弹出排列设置，默认横向排列；执行后
还可用 F9 修改模式和间距。

- **横向排列**：首岛不动，其他所选岛按各自 AABB 的宽度向右依次排开。
- **纵向排列**：首岛不动，其他所选岛按各自 AABB 的高度向上依次排开。
- **跨象限**：用于烘焙。堆叠组原先位于第一象限（0~1）时，首岛留在第一象限，
  其他所有岛整体平移 `(+1, 0)` 到右侧下一象限。它们仍保持彼此原有的重叠关系。

“岛间距”仅用于横向/纵向排列，默认 0.01 UV 单位。三个模式均只平移，不缩放
或旋转，不改变岛内顶点的相对位置。“跨象限”保留首岛原位，保持精确 +1U 平移。

首岛优先使用活动物体的活动面所在所选岛；没有有效活动面时，取活动物体的
首个所选岛，再按物体名/面索引稳定排序。选中岛的一部分 UV 即处理该可见岛。
按编辑器可见范围执行，未显示/隐藏的 UV 和未选中的其他岛保持原位。

支持 Blender 4.5 / 5.2 的 UV 同步开关与点/边/面/岛选择，多物体与共享网格。
选择、pin、seam、其他 UV 层及网格几何保留；写回失败恢复坐标，支持 Undo/Redo。

测试：`tests/test_uv_unstack.py`（5 项纯算法），
`tests/test_blender_uv_unstack.py`（每版 11 项原生集成测试，含模式/同步/选择组合）。
