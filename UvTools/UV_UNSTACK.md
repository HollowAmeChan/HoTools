# 取消堆叠

UV 编辑器右键 → HoTools → **取消堆叠**，位于“拓扑堆叠”正下方。
也可 F3 搜索“取消堆叠 UV 岛”。执行前弹出排列设置，默认横向排列；执行后
还可用 F9 修改模式和间距。

首先按所选岛的实际 UV 面积重叠关系划分**工作区**：完全重合或部分交叠属于
同区；A 与 B 重叠、B 与 C 重叠时，三者都属于同区。仅边/点接触或仅 AABB
相交不算重叠；凹岛及孔洞的空白区域也不算。每个工作区分别执行以下排列：

- **横向排列**：每区首岛不动，区内其他岛按各自 AABB 的宽度向右依次排开。
- **纵向排列**：每区首岛不动，区内其他岛按各自 AABB 的高度向上依次排开。
- **跨象限**：用于烘焙。工作区原先位于第一象限（0~1）时，各区首岛留在原位，
  区内其他所有岛整体平移 `(+1, 0)`。它们仍保持彼此原有的重叠关系。

单岛工作区允许执行，保持原位，不要求至少两个岛。不进行跨工作区的全局
避让，某区排列后的岛即使与其他区重叠，也不再移动其他区。

“岛间距”仅用于横向/纵向排列，默认 0.01 UV 单位。三个模式均只平移，不缩放
或旋转，不改变岛内顶点的相对位置。“跨象限”保留每区首岛，保持精确 +1U 平移。

每区首岛优先使用活动物体的活动面所在所选岛；其次优先活动物体，再按物体名/
面索引稳定排序。选中岛的一部分 UV 即处理该可见岛。
按编辑器可见范围执行，未显示/隐藏的 UV 和未选中的其他岛保持原位。

支持 Blender 4.5 / 5.2 的 UV 同步开关与点/边/面/岛选择，多物体与共享网格。
选择、pin、seam、其他 UV 层及网格几何保留；写回失败恢复坐标，支持 Undo/Redo。

共享网格边的镜像岛精确重叠后，Blender 原生 Ctrl+L 可能把它们连选，普通 UV
连续性检测也会将其合并。本工具按共享边两侧的 UV 面朝向识别这种折叠重叠，
将其作为独立岛排列；已经堆叠的数据也可直接处理，无需重新堆叠或撤销。
原生 Ctrl+L 的连选行为仍由 Blender 决定；本工具不添加微量偏移，不拆开网格。

测试：`tests/test_uv_unstack.py`（5 项纯算法），
`tests/test_uv_overlap.py`（9 项重叠工作区纯算法），
`tests/test_blender_uv_unstack.py`（每版 21 项原生集成测试，含原生 Ctrl+L 后的
单面/多面恢复、独立工作区、部分重叠、凹岛、单岛、跨区允许重叠与状态保留）。
