# UV 线长度均化

UV 编辑器中选择一条或多条不相交的开链，右键 → HoTools → **长度均化**，
或 F3 搜索 **UV线长度均化**。网格工具饼 UV 区也有入口（拉直均化）。
立即执行，无设置窗口。

每条线的两个端点坐标保持原位，只调整中间 UV 点：将线拉直到两端连线上，
按对应 3D 网格边长的累计比例分布。例如边长 `1:2:1`，中间两个点位于端点
跨度的 `1/4`、`3/4`，UV 各段长度也成为 `1:2:1`。

3D 长度来自当前编辑网格，并计入物体的世界变换与非均匀缩放，不读取修改器
计算后的其他拓扑。每条线独立处理，不统一不同线的 UV/3D 缩放比例。
共享 mesh 只写一次；活动物体使用该 mesh 时，优先按活动实例的变换测量，
否则使用按名称排序的首个编辑实例。

关闭同步时使用 UV 边选择模式，开启同步时 4.5 使用网格边选择模式；5.2
有效的精细 UV 边选择也可独立于网格面选择模式处理。读取真实选边标记，
不通过两个顶点被选中来猜测边。

支持多物体、多岛和同岛多条不相交开链；接缝两侧独立处理。按编辑器可见
范围处理，隐藏和未显示的面角点保持原位。中间点的可见连续 UV 面角点一起
移动，保持连接；其他 UV 点、两端的每个实际面角点和其他 UV 层保持原位。
pin 标记保留，中间点即使有 pin 也依照本次明确的选线操作移动。
网格几何、选择、seam、同步开关与变换轴心均不改变，支持 Undo/Redo。

至少选择两条相连的边。单边没有中间点，不处理。分叉、闭环、两端重合或
3D 总长度为零时在写入前取消整个操作。个别 3D 零长边的对应 UV 段归零。
写回失败会恢复每个实际角点的原坐标。

纯函数：`Utils/uv_chains.py::distribute_chain_by_lengths`。
实现：`UvTools/length.py`。测试：`test_uv_length.py` 6 项纯算法通过；
`test_blender_uv_length.py` 15 项原生测试，4.5.8 为 13 通过、2 项新版 API
测试跳过，5.2.0 为 15 项全部通过。覆盖端点、3D 比例、多线/岛/物体、
世界缩放、真实选边、现代同步状态、隐藏范围、共享 mesh、回滚与 Undo/Redo。
