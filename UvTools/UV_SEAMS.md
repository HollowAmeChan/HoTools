# UV 岛边界标记缝合边

选中需要处理的 Mesh 后，F3 搜索 **UV岛边界标记缝合边**，立即执行。
也可从 UV 编辑器右键 → HoTools → **UV边界缝合边**、网格工具饼的 UV
工具区，或数据属性 UV 贴图下的边图标使用。

物体模式和多物体网格编辑模式均可使用；每个所选 Mesh 按自己的当前活动
UV 层处理所有面，包括隐藏和未选中的面。不要求选择 UV，也不受 UV 同步
开关影响。共享网格只处理一次，非 Mesh 与没有活动 UV 的网格跳过。

共享边两个端点的 UV 不连续时标记为 seam，网格表面外边界也标记。
边界检测包含仍通过其他面路径相连的内部 UV 切口，以及镜像精确堆叠后
共享边两侧折叠到 UV 同侧的边界。整体镜像与反向网格面本身不会造成误切。
容差为 `1e-7` UV 单位；孤立线段没有 UV 面，不新增标记。

操作只追加 seam。UV 坐标、各层、pin、网格几何、物体与网格/UV 选择均
保持原状。支持 Undo/Redo；写回失败则恢复新增标记。切换活动 UV 后再次执行，
可将不同 UV 的分割累计到网格 seam 中。

实现：`UvTools/seams.py`；公共检测：`Utils/mesh_uv.py::uv_boundary_edges`。
原生测试：`tests/test_blender_uv_seams.py`，Blender 4.5.8 / 5.2.0 各 16 项通过，
覆盖模式/同步/选择组合、隐藏面、多物体不同活动层、单端点断开、内部切口、
镜像重叠、非流形边、共享网格、形态键/自定义属性保留、回滚与撤销重做。
