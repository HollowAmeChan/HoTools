# HoTools

HoTools 是一组面向 Blender 角色、模型、贴图、动画和自动化流程的工具集合。插件按模块组织，常用工具会出现在 3D 视图侧栏 `HoTools`、右键菜单、属性面板或 OmniNode 节点图里。
